# Dynamic User Interface

Dette projekt er udviklet som en prototype i forbindelse med et skoleprojekt på Erhvervsakademi Aarhus.

Løsningen er inspireret af Google Keep, men er genfortolket som en analog, mindeværdig notesblok med papir-inspireret design og taktile animationer.

## Funktioner

- Opret, rediger og søg i noter
- Kombiner almindelig tekst og checklister i samme note
- Organiser noter i tavler og etiketter
- Vælg farve og papirlayout
- Arkiver og flyt noter til papirkurven
- Automatisk gemning

## Teknologier

- Next.js
- React
- JavaScript
- CSS Modules
- Supabase
